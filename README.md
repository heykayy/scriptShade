## ✨ Features

### 🎯 AI-Powered Flashcard Generation
- **Instant Creation**: Generate 10+ quality flashcards in seconds
- **Any Topic**: Works with ANY subject - Python, History, Science, AI, etc.
- **Multiple Types**: Definition, explanation, application, examples, characteristics
- **Difficulty Levels**: Easy, Medium, Hard - adapts to your skill level

### 📝 Smart Quiz Mode
- **Real-time Evaluation**: Semantic matching understands meaning, not just exact words
- **Confidence Scoring**: See how confident the AI is in your answer
- **Detailed Feedback**: Get constructive feedback and improvement suggestions
- **Streak Tracking**: Keep track of your consecutive correct answers

### 📊 Progress Analytics
- **Session Statistics**: Score, accuracy, time spent
- **Answer History**: Review your previous answers
- **Category Breakdown**: See performance by topic category
- **Review Mode**: Focus on questions you got wrong

### 🔒 Privacy & Offline First
- **100% Offline**: No internet connection required
- **Private**: All processing happens on your machine
- **Free**: No API keys, no subscriptions, no hidden costs
- **Portable**: Save and load sessions as JSON files

### 🎨 User Experience
- **Modern GUI**: Clean, intuitive interface with three-panel layout
- **Keyboard Shortcuts**: Enter to submit, arrow keys to navigate
- **Hint System**: Get hints when you're stuck
- **Dark/Light Mode**: Auto-adjusts to your system theme

## 🚀 Installation

### Prerequisites
- Python 3.9 or higher
- 4GB RAM (minimum)
- 2GB free disk space

### Method 1: Quick Install (Recommended)

```bash
# Clone the repository
git clone https://github.com/yourusername/flashcard-master.git
cd flashcard-master

# Install dependencies
pip install torch transformers

# Run the app
python main.py
